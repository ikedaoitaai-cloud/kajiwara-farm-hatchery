# 🐣 孵化率予測システム

カジワラファーム様向け 孵化率予測 Web アプリケーション

**▶ 公開URL: https://ikedaoitaai-cloud.github.io/kajiwara-farm-hatchery/**

## 概要

お客様からの「来月1万羽のヒヨコをください」という注文に対し、何個の卵を仕込めばよいかを予測するシステムです。

**現状**: お母様の手計算（精度70-75%）
**目標**: システム化により精度85-90%へ改善

インストール不要。ブラウザで上記URLを開くだけで使えます。データはブラウザ内（LocalStorage）に保存され、サーバーには送信されません。

## 主な機能

✅ **複数農場の入卵データ管理** — 農場は何件でも追加でき、合計を自動計算
✅ **リアルタイム予測** — 入力と同時に予測メス鶏数が更新（計算ボタン不要）
✅ **2つの予測モデル** — 区分線形（推奨）／非対称正規分布（参考）を管理画面で切替
✅ **カレンダー起点の実績入力** — 入力状況を色分け表示、実績入力で精度を即時算出
✅ **データ出力** — CSV出力／JSONバックアップ／復元
✅ **管理画面** — 計算モデル・補正係数・計算式の全体像を画面上で確認
✅ **大きな文字と広いタップ領域** — PCに不慣れな方でも扱えるUI

## 使い方

### 予測を出す

1. 「入卵数の計算」を開く
2. 入卵日を確認（初期値は今日）
3. 農場名・親鳥日齢・入卵数・貯卵日数を入力 → **予測が自動表示**
4. 必要なら「＋ 農場を追加する」で複数農場を登録
5. 「この結果を保存する」で記録

### 実績を記録する

1. 「孵化実績入力」を開く
2. カレンダーで色のついた日付を選択（黄＝未入力、緑＝完了）
3. 農場ごとに実際のメス鶏数・総孵化数を入力 → **精度が即座に表示**
4. 「実績を保存する」

詳細は [USER_MANUAL.md](./USER_MANUAL.md) を参照してください。

## 予測アルゴリズム

```
農場ごとの総孵化数 = 入卵数 × 基礎孵化率(親鳥日齢) × 貯卵日数補正 × 季節補正
総孵化数           = 全農場の合計
予測メス鶏数       = 総孵化数 × 61%
```

**基礎孵化率（区分線形モデル・推奨）**

| 親鳥日齢 | 孵化率 |
|---|---|
| 165日以下 | 20% |
| 165〜230日 | 20% → 40%（線形上昇） |
| 230〜250日 | 40%（ピーク） |
| 250〜530日 | 40% → 35%（線形下降） |
| 530日以上 | 35% → 32% |

**基礎孵化率（非対称正規分布モデル・参考）**

```
孵化率 = 24.5 + 15.5 × exp(−0.5 × ((日齢 − 240) / σ)²)
σ = 32（日齢240以下） / 300（日齢240超）
```

**補正係数**

| 貯卵日数 | 係数 | | 季節 | 係数 |
|---|---|---|---|---|
| 7日以内 | ×1.00 | | 2〜5月・10〜12月 | ×1.00 |
| 8〜10日 | ×0.95 | | 1月（正月明け） | ×0.95 |
| 11〜16日 | ×0.85 | | 6〜9月（夏期） | ×0.92 |
| 17日以上 | ×0.60 | | | |

詳細は [PROJECT_OVERVIEW.md](./PROJECT_OVERVIEW.md) を参照してください。

## 既知の制限事項

- **LocalStorage依存** — ブラウザキャッシュのクリアでデータが消失します。「📤 出力」からの定期バックアップを推奨
- **複数デバイス間で同期不可** — バックアップ／復元による手動移行が必要
- **オフライン非対応** — CDN依存のためインターネット接続が必須
- **CSV出力は区分線形モデルのみ** — 非対称正規分布の予測値はCSVに含まれません

LocalStorage・同期の制限は Phase 2 のバックエンド開発で解決予定です。
